# E-Commerce Full-Stack Application

A modern, scalable e-commerce platform with user authentication, product browsing, cart management, checkout, and admin panel.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Node.js](https://img.shields.io/badge/Node.js-v14%2B-green)
![MongoDB](https://img.shields.io/badge/MongoDB-4.0%2B-blue)

## 🚀 Features

- **User Authentication** (Register/Login with JWT)
- **Product Catalog** with search, filters & pagination
- **Shopping Cart** (Add, remove, update items)
- **Secure Checkout** with Stripe integration
- **Order History & Tracking**
- **Admin Dashboard** (CRUD for products, users, orders)
- **Responsive UI** (Mobile-first design)
- **Email Notifications** (Order confirmation via Nodemailer)

---

## 🛠️ Tech Stack

| Layer        | Technology                          |
|-------------|-------------------------------------|
| Frontend    | React.js / HTML, CSS, JavaScript    |
| Backend     | Node.js + Express.js                |
| Database    | MongoDB (Mongoose ODM)              |
| Auth        | JWT + bcrypt                        |
| Payments    | Stripe                              |
| Styling     | Tailwind CSS / Bootstrap            |
| Deployment  | Vercel (Frontend), Render/Heroku (Backend) |
